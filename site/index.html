How this works. The index is built from OpenNeuro's public GitHub mirror (github.com/OpenNeuroDatasets). For each dataset it reads dataset_description.json, the README, participants.tsv and .json, phenotype files (headers and sidecars), one PET sidecar's TracerName, and the full list of file names. No imaging data is downloaded. File names are collapsed across subjects and runs into patterns.

Limits. The index is rebuilt on a schedule, so datasets published since the date at the top won't appear yet. Ages come from the first age column in participants.tsv, converted to years when the sidecar gives months, weeks or days; ages over 120 with no stated units are left out. Sex counts are skipped when values are numeric codes with no Levels in the sidecar. READMEs are cut off at 20,000 characters and file lists at 250 patterns per dataset. Check the dataset's page on OpenNeuro for its current version.
